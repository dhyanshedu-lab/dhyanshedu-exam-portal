# DhyanshEdu Exam Portal deployment

The portal is deployed as a separate Cloudflare Pages project: `dhyanshedu-exam-portal`.

- Source repository: `dhyanshedu-lab/dhyanshedu-exam-portal`
- Production branch: `main`
- Build command: none (static HTML, CSS and JavaScript)
- Output directory: repository root
- Initial test hostname: `dhyanshedu-exam-portal.pages.dev`

The existing public website and API Worker are separate and must not be overwritten by this deployment.
